# 计算化学与药物发现建模护栏 (CompChem & Cheminformatics Reference)

处理小分子结构-活性关系（SAR）、剂量-反应测定、ADMET/QSAR 预测及多精度分子模拟时，除遵循主文件四步规程外，逐项核对以下领域规则。工具选择默认在 Python 沙箱中使用 `RDKit` 进行分子标准化、指纹/描述符计算与母核提取。

---

## 1. 数据与机理建模分支：实验测定与物理化学拟合

### 1.1 剂量-反应曲线拟合 (4PL Dose-Response: $\text{IC}_{50}$ / $\text{EC}_{50}$)
四参数逻辑方程 $y = \text{Bottom} + \frac{\text{Top} - \text{Bottom}}{1 + (x / \text{IC}_{50})^{\text{Hill}}}$ 不能只拟合完报一个点估计值，必须核查四项物理合理性：
1. **上下渐近平台收敛**：实验测试浓度梯度是否覆盖了低浓度基线平台（Bottom）与高浓度饱和平台（Top）？若最高测试浓度仅达到 45% 抑制率，自由拟合的四参数 $\text{IC}_{50}$ 方差极大且不可信——此时应对比固定平台约束（如根据阴/阳性对照固定 0% 与 100%）的敏感性，或如实标记为外推不确定（`> max_conc`）。
2. **Hill 斜率诊断**：理想单一位点可逆竞争结合的 Hill 斜率接近 $1.0$。若拟合出异常陡峭的曲线（$\text{Hill} > 2.5$），主动提示可能存在**化合物胶体聚集（Colloidal Aggregation）、共价不可逆反应或细胞毒性假阳性**；若 $\text{Hill} \ll 0.5$，提示非特异结合或溶解度析出限速。
3. **对数尺度参数化**：活性与效价参数（$\text{pIC}_{50} = -\log_{10}(\text{IC}_{50}\text{ [M]})$、$\text{p}K_i$、$\Delta G = RT \ln K_d$）在自由能尺度上近似服从加和与正态误差，**统计检验、置信区间计算与回归建模一律转换至 $\text{pIC}_{50}$ / $\Delta G$ 线性自由能尺度进行**，切勿直接在跨数量级的原始 $\mu\text{M}/\text{nM}$ 数值上算算术平均或最小二乘残差。
4. **异方差与离群复孔**：检查高浓度与低浓度复孔方差是否齐性，必要时采用稳健回归（Huber / Cauchy 损失）抑制坏孔干扰，并叠加原始复孔散点绘图。

### 1.2 截断/删失活性值与多来源测定噪声 (Censored & Heterogeneous Assays)
- 文献或公共库（ChEMBL / PubChem）表格中常见的 `> 10 μM`、`> 100 μM`、`< 0.1 nM` 属于**区间/右删失数据（Censored Data）**：
  - **禁止**直接把 `>` 号删掉当成精确值 `10 μM` 混入回归（会严重扭曲斜率并压缩低活性端方差），也禁止无条件全部丢弃（会造成仅保留活性分子的幸存者偏差）。
  - **规范**：在数据建模中使用删失回归（Tobit 模型 / 生存似然）；在算法建模中或改为合理阈值的二分类/序数分类任务，或在损失函数中对删失样本使用单侧铰链损失（One-sided Hinge Loss）。
- 合并公开数据库多文献活性前，必须过滤测定类型混杂（绝不把结合实验 $K_i$、酶活 $\text{IC}_{50}$ 与细胞表型 $\text{EC}_{50}$ 混为同一连续标签而不加区分），并检查同一分子跨实验室测定值的标准差（测定噪声天花板决定了任何预测模型可能达到的理论最高 $R^2$！）。

### 1.3 小样本同系物的机理/加和建模 (Free-Wilson & LFER)
- 当同一母核（Core）下的湿实验合成序列仅有 $n = 15 \sim 50$ 个分子时，直接训练深度图神经网络（GNN）毫无意义。优先采用 **Free-Wilson 取代基加和回归**（Ridge/Lasso 拟合各 R 位点取代基贡献及成对非加和交互项）或基于物理有机参数（Hammett $\sigma$、$\text{cLogP}$、$\text{TPSA}$、$\text{p}K_a$、埋藏体积 $\%V_{\text{bur}}$）的线性自由能关系模型。

## 2. 算法建模分支：QSAR / ADMET 与分子机器学习护栏

### 2.1 分子结构规范化先行 (Chemical Standardization)
任何特征提取与数据切分前，先用 `RDKit` 完成清洗：去盐/去溶剂碎片保留母体分子、电荷中和与互变异构体规范化（Canonical Tautomer）、检查手性立体中心是否缺失（若外消旋体与纯对映体混杂且活性差异显著，需单独标注）以及按 InChIKey 去重/聚合重复测定值。

### 2.2 防孪生泄漏的切分铁律 (Scaffold, Cluster & Temporal Splits)
- **严禁将随机切分（Random Split）作为 QSAR 模型的唯一评估指标！** 药物化学数据集存在高度同源的同系物簇（只差一个卤素或甲基），随机切分测出的高 $R^2$/AUC 只是局部记忆，换一个新化学系列立刻失效。
- **规范切分**：
  1. **时间切分 (Temporal Split)**：若有化合物合成/入库时间戳，最贴近真实药物发现前瞻性预测场景。
  2. **Bemis-Murcko 母核切分 (Scaffold Split)** 或 **Butina 指纹聚类切分 (Cluster Split，如 Morgan ECFP4 Tanimoto 阈值 0.4–0.6)**：评估跨母核泛化（Lead Hopping）能力。
  - 建议同时汇报分组/母核切分结果（真实外推能力）与簇内分层切分结果（同系列结构优化能力），让药化团队清楚模型在“换骨架”与“改取代基”两种场景下的真实表现。

### 2.3 活性悬崖诊断 (Activity Cliffs)
- 在建模前扫描数据集中 **结构高度相似（如 ECFP4 Tanimoto $\ge 0.85$ 或配对分子对 MMP 单点变换）但 $\text{pIC}_{50}$ 相差 $\ge 1.0 \sim 2.0$ 个数量级** 的分子对。
- 活性悬崖既是药化机制的核心线索（关键氢键得失、构象翻转、空间碰撞），也是平滑机器学习模型误差最大的区域：单独汇报模型在悬崖子集上的 RMSE，并用配对分子对分析（MMPA）展示驱动悬崖的关键基团变换。

### 2.4 适用域 (Applicability Domain, AD) 与多精度算力漏斗
- **适用域强制标注**：对虚拟筛选或新设计的候选分子打分时，计算每个候选分子到训练集最近 $k$ 个分子的 Morgan 指纹 Tanimoto 相似度（如 $S_{\max} < 0.35$ 标记为 **Out-of-Domain 低置信度外推**），结合集成方差或保形预测区间一并交付。
- **多精度算力漏斗 (Multi-Fidelity Compute Ladder)**：
  1. **L1（毫秒/分子，CPU 前台）**：RDKit 2D 理化描述符 + Morgan 指纹 + Ridge / Random Forest / LightGBM 基线，以及 PAINS/反应性结构警报过滤。
  2. **L2（秒~分/分子，CPU 沙箱或后台 `jobs`）**：ETKDGv3 3D 构象系综、质子化态枚举、构象应变能、Vina/smina 分子对接。
  3. **L3（分钟~小时级，GPU `scienceModels` 或重型后台作业）**：全原子共折叠（如 OpenFold3 / Boltz）、半经验量子力学（xTB）、分子动力学（OpenMM）与炼金术相对结合自由能（RBFE/FEP）——**仅在 L1/L2 漏斗筛剩的少量优胜分子上运行，且运行前显式确认算力与时间预算**。
